# Formato do RESOURCES.md

O `RESOURCES.md` é o conjunto selecionado de fontes confiáveis sobre o assunto. O conhecimento das explicações deve sair daqui, não de palpites paramétricos. A sabedoria vem das comunidades listadas aqui.

## Estrutura

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Regras

- **Só alta confiança.** Prefira fontes primárias, especialistas reconhecidos, trabalhos revisados por pares e comunidades com moderação forte. Se uma fonte é marketing disfarçado de educação, deixe de fora.
- **Comente cada entrada.** Um link solto não serve para nada daqui a três meses. Acrescente uma linha: o que ele cobre e quando recorrer a ele.
- **Agrupe em Conhecimento / Sabedoria.** Espelha a filosofia de [SKILL.md](./SKILL.md). Tudo bem uma fonte aparecer em só um dos grupos.
- **Aponte as lacunas de forma explícita.** Se não existe uma boa fonte para uma área de que a missão precisa, escreva uma seção `## Gaps` listando o que falta. Isso orienta as próximas buscas.
- **Corte sem dó.** Uma fonte que se mostrou errada, rasa ou fora da missão deve ser removida, não enterrada. Melhor cinco fontes certeiras que trinta medianas.
- **Registre as preferências sobre comunidades.** Se o usuário optou por não participar de comunidades, anote isso aqui para que as próximas sessões não fiquem propondo isso de novo.
