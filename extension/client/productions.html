registro de uso

drives da rede

a letra do Windows e o caminho de rede que ela representa. o padeiro usa este mapa para converter caminhos entre Windows e Mac (conversor, busca e caminhos dos templates).

volumes sem letra

volumes montados no Mac (/Volumes/NOME) que não têm letra no Windows: o nome do volume e o servidor onde ele está.

servidor padrão

usado quando o volume não está em nenhuma das listas acima.

tipos de peça

ao renomear, o padeiro procura um destes termos no nome da comp (ou da pasta dela) e aplica o prefixo e o comentário do tipo: rodapé_joão silva → RDP - JOAO SILVA. a ordem importa: vale o primeiro tipo encontrado (arraste para reordenar). os termos são palavras separadas por vírgula; o plural com S também vale.

prefixocomentáriotermos

nomes fixos

a comp que tem o termo no nome (ou no comentário) passa a se chamar sempre o mesmo nome.

tipos de item

arraste cada tipo para a pasta da árvore que deve recebê-lo. o que fica na raiz não entra em pasta nenhuma. as pastas também se arrastam: sobre outra pasta, ela entra; entre duas, fica no mesmo nível.

comps de render

a comp vai para a pasta das comps de render quando o comentário dela contém um destes termos (ou o comentário de um tipo de peça da aba renomear).

dado às comps selecionadas sem comentário (ao organizar) e às comps criadas pelos templates.

comps editáveis

com uma pasta para as comps editáveis na árvore, a comp vai para ela quando o comentário contém um destes termos (ex: EDIT, EDITAR). sem essa pasta, elas ficam com as outras comps.

arquivos

tipos de arquivo

o collect copia os arquivos usados no projeto para a pasta do projeto (a do .aep) e troca os caminhos no projeto. arraste cada tipo para a pasta que deve recebê-lo; o que fica na raiz (riscado) não é coletado.

sequências de imagens

copiadas inteiras (os quadros do trecho usado), cada uma numa subpasta com o nome dela (render_0001.png → render). a interpretação do item (fps, alpha) é mantida.

opções

índice

de onde vem o índice de caminhos (atrações, projetos e outputs) que a busca usa.

categorias

identificadas automaticamente no índice (cada lista dele vira uma categoria). dê a cada uma o nome que aparece na busca; sem nome, vale o automático.

pasta dos projetos

onde os projetos são salvos. a pasta de cada retranca fica dentro desta; sem pasta, a janela PROJETO pede uma ao salvar.

nomes

o nome do arquivo .aep, com as variáveis {id} {projeto} {usuario} (a sigla) {retranca} {data}. o nome do projeto segue o formato da aba RENOMEAR (acentos e caixa).

retrancas

o começo do ID do projeto indica a retranca: EMP123456 → a pasta de EMP. a pasta pode ser dentro da pasta dos projetos (JORNAIS/em ponto) ou um caminho completo. vale o código mais longo que combinar.

logo da barra

a imagem é reduzida para caber na barra (até 96 x 72 px), sem cortar. PNG com fundo transparente fica melhor.

fora da barra

a barra de todo mundo, à esquerda, na ordem: arraste pelos pontinhos para reordenar e use o × para tirar uma ferramenta (ou os links). o que sai aparece aqui: o + põe de volta, no fim da barra. os separadores dividem a barra em grupos; '+ separador' (abaixo) acrescenta um no fim da barra.
