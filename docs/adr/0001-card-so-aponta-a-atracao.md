# O card do Trello só aponta a atração; o projeto não guarda dados de produção

N'O PROJETISTA (a janela de projeto), o card do Trello serve para achar a atração (pelo vínculo do card no banco, `atr` no índice) e, no
tipo fixo, o mês. O `.aep` não leva o nome do card, e os metadados do projeto não guardam card nem produção: a
equipe pediu para não armazenar a produção no projeto (o registro de uso fica no padeiro_log).
