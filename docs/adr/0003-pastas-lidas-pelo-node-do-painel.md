# As pastas são lidas pelo Node do painel, não pelo host

Conferir se um filme já tem projeto (a pasta da letra) e listar pastas grandes no host (ExtendScript) trava o After
Effects. O host só converte os caminhos (o volume montado no Mac); o Node do painel lê as pastas sem bloquear. Sem o
Node (navegador de teste), o host lê como plano B.
